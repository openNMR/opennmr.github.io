The first time you open it

The installers are not yet code-signed, because signing certificates are paid for and openNMR is a free project. The apps are safe to run, but your computer will ask you to confirm once:

Windows
SmartScreen says “Windows protected your PC”. Click More info, then Run anyway.
macOS
The first launch is blocked (“cannot be opened” or “Apple could not verify”). Open System Settings ▸ Privacy & Security, scroll to the message about openNMR and click Open Anyway.
Linux
If the AppImage will not start because FUSE 2 is missing, run it with --appimage-extract-and-run.

Check your download

Each file's SHA-256 checksum is shown above. To confirm a download is intact, compute it and compare:

# Windows (PowerShell)
Get-FileHash .\openNMR-0.9.6-windows-setup.exe -Algorithm SHA256

# macOS
shasum -a 256 openNMR-0.9.6-macos-arm64.dmg

# Linux
sha256sum openNMR-0.9.6-linux-x86_64.AppImage

App or pip?

The app and the Python package are built from the same code and have the same features. The app is the easiest way to start. Choose pip if you want to use openNMR from a Jupyter or Colab notebook (from opennmr import notebook as nmr), which the app cannot do. The two are separate copies, so updating one does not change the other.
