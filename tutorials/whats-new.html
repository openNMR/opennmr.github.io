0.9.12 to 0.9.13 (12 November 2026)

Measure in ppm and Hz on every plot, a crosshair through every row of Simulate's stacked plots, easier-to-read DOSY and BMS reports, a scrolling message when a state opens, and a sortable folder list.

  • Measure everywhere. On Compare ▸ Superimposed, Measure gave a bare number with no unit; it now gives ppm and Hz, as it already did on a stack. The same holds on Compare's panels (1D and 2D), the heatmap, the DOSY map and the processing preview, for x and for y on a 2D. Where an axis is not a chemical shift, the distance takes the unit on its label instead (for example a delay in s, a pulse time in µs, or D in m² s⁻¹ with the ratio between the two points on its log axis). A Compare drawn after you switched a 1D to Hz is measured correctly too (the unit was carried over wrongly before), and a stack keeps your unit. See Open ▸ the plot toolbar.
  • Crosshair on Simulate's stacked plots. On a SIMPSON pulse shape (amplitude, phase and offset against time) the vertical line runs through every row, as in a stacked Compare, so you can read the same moment off each. On a Bloch simulation, the pulse and its excitation profile each get their own crosshair, since their x axes differ. Before, only the first plot had one. See Simulate.
  • DOSY and BMS reports laid out like the curve fit. The DOSY map's report has a title, the regularisation α, and a table of each peak's shift, D and spread, in place of the fixed-width block. The BMS simulation's report gives the shift's mean, standard deviation and FWHM as one row, then the susceptibility, local interactions, run time and any warnings, each in its own section.
  • Opening a state with many spectra. File ▸ Open openNMR State… said what it had done in a message that ran off the bottom of the screen for a large state. It is now a scrolling window that groups the spectra by outcome, gives their shared folder once, and has a Copy button.
  • Sort the experiments in Browse a folder. Right-click the list ▸ Sort by: name, A to Z or Z to A (numbers in order, so 2 comes before 10), or date, newest or oldest first. The date is when the data were acquired, not when the folder last changed. Your choice is remembered.

0.9.11 to 0.9.12 (10 November 2026)

Removing points from a curve fit, the log PFG plot, SCORE residuals, a single list of insets, integral calibration, TopSpin's TDeff and cubic particles.

  • Dynamics: remove a point with a right-click. On the curve fit, one peak or all peaks together, right-click ▸ Remove Point takes the point nearest the click out of that peak's fit and refits it; Remove Slice from Every Fit drops the whole slice from every peak, SCORE and the DOSY ILT; Restore Removed Points puts them back. Removed points stay on the plot as a faded ×, or untick Show removed points to leave them off. Slices used in fits folds away like the other sections, and its title says how many slices are excluded. See Dynamics.
  • The log plot of a PFG series. Right-click the curve ▸ Curve Fit Plot… ▸ y axis: the intensity as measured, I/I0, or ln(I/I0). I0 is the fitted curve at b = 0, so the whole series sets the scale rather than one point. Against b, ln(I/I0) is the Stejskal–Tanner plot: a straight line of slope −D for one species, curved for more. The uncertainty band is carried across; points at or below zero, which have no logarithm, are left out and counted. In a notebook: nmr.attenuation(fit, mode="ln").
  • SCORE and OUTSCORE. With a multi-component Model selected (a biexponential, N-component diffusion), SCORE now uses its single-component form instead of stopping with an error, and says so: its own number of components does what the extra terms did. The report is laid out like the curve fit's and adds the RMSE, the residual as a share of the signal and the worst-fitting slice, which finds a spoiled slice that one R² averages away. Tick Residual in the component list to draw measured − fit on the same scale as the components. The SCORE list and its tick boxes now belong to the experiment they were run on, rather than staying on screen for the next one.
  • Insets: one list, in Plot Style. The inset controls are now the Insets section of Plot Style (right-click ▸ Inset… opens it there), which scrolls and never opens taller than the screen. On a Compare stack the list holds every spectrum's insets, so each can be edited or removed whichever spectrum is selected, and Placed in sets an inset in another spectrum's area, beside that spectrum's own. Region limits take any number (an intensity axis of 1010 was cut to 109 before), and an inset's x- or y-axis label, ticked with no text of your own, takes the plot's.
  • Calibrate integrals on the plot. Right-click an integration region ▸ Calibrate Integral Here…, type what it should be (3 for a CH3), and every other region's label scales with it. The calibration stays with the spectrum and follows the region if you move it; Reset Integral Calibration goes back to the smallest = 1. In a notebook: integral_labels(spectrum, regions, reference=(k, value)).
  • Truncate to in TopSpin's terms. Process ▸ FID Processing ▸ Truncate to now takes TDeff as TopSpin counts it (real and imaginary points, digital filter included), so the number in edp can be copied across; switch it to complex points if you prefer.
  • BMS shifts. Cuboid particles (cubes when the sides are equal, given by their edge lengths); sizes in nm, µm or mm; the box is now the Simulated region, a periodic piece of the powder whose side follows from the packing fraction (or set it), clearly separate from the Sample container whose dimensions are named for what it is; diamond and sapphire rotors; the nucleus chosen from a list; and each Packing method explained when you hover over it. See Simulate.

0.9.10 to 0.9.11 (9 November 2026)

JEOL 2D data, and curve-fit reports that are easier to read.

  • JEOL 2D and pseudo-2D. openNMR now opens 2D JEOL Delta .jdf files as well as 1D ones. A genuine 2D (HSQC, HMQC, COSY style) is transformed in both dimensions; a pseudo-2D series (saturation or inversion recovery and the like) opens as one spectrum per delay, and Dynamics ▸ Delays ▸ Auto uses the delays the file records, saying where they came from. The file says which kind a 2D is, so it opens that way, and Process Indirect Dimension still switches between the two. Every direct-dimension processing option applies; in F1 you get window, zero-fill and truncation. Field drift correction works on JEOL series. Checked on a 14N–1H HMQC and a 1H saturation recovery recorded at 70 kHz MAS, against the same HMQC processed independently. In a notebook: opennmr.io.load("file.jdf"). See Supported data.
  • Dynamics: a readable curve-fit report. The report under the fitted curve used to be a block of fixed-width text. It now leads with the fitted T1, T2 or D in large type, with the peak or region as its title and the model beneath. Every parameter follows in a table, with italic symbols, units, uncertainties and, for several components, each amplitude's share of the total. The fit-quality numbers form one row, and what the ± means is spelt out underneath. Several peaks are summarised in one table, and a global fit leads with the shared parameter. Copying, CSV export and kept fits still use the plain-text report. See Dynamics.

0.9.9 to 0.9.10 (7 November 2026)

Paramagnetic NMR tools: bulk magnetic susceptibility shifts, shifts against temperature and bond pathways.

  • Paramagnetic NMR tools, in one optional section. Simulate ▸ Paramagnetic NMR tools holds pNMR (CIF), Shift against temperature, Bulk magnetic susceptibility (BMS) shifts and Bond pathways from DFT. It is off until you switch it on, in Settings ▸ Sections shown ▸ Paramagnetic NMR or by choosing Paramagnetic NMR in Help ▸ Welcome to openNMR…; the same switch shows Fit ▸ pNMR (CIF bond pathways). If you used pNMR (CIF) before, it has moved here and is hidden until you switch it on. See Simulate.
  • BMS shifts from a packing of particles. Generate a random packing (ellipsoids, hexagonal prisms or tori, with a spread of sizes) or read a LAMMPS dump file, give the particles' susceptibility (one value, or three principal values in each particle's frame), and openNMR calculates the field from every particle and the spectrum of nuclei inside the particles, between them, or both. The sample can be a MAS rotor (0.4, 0.7, 1.3, 1.9, 2.5, 3.2, 4.0 or 7.0 mm, with the inner diameter corrected for the wall), a tube, a plate at any angle to B₀, or a sphere; the shape of the packed powder adds its own shift across the sample, and the rotor's wall and caps add theirs. The observed nuclei can also have a contact shift, a spin-dipolar anisotropy and a quadrupolar coupling. Static spectra, infinitely fast MAS, or MAS with spinning sidebands. Show switches between the spectrum, a slice of the field and a 3-D view of the packing without simulating again. A run expected to take more than 10 s asks first, with what would make it faster. Keep in Open Experiments adds the spectrum to your data. In a notebook: nmr.fast_bms_spectrum.
  • Susceptibility in the units you have. SI volume (or in ppm), cgs volume, cgs or SI mass (with the density), cgs or SI molar (with the molar mass and density, or the unit-cell volume and Z), or μeff per paramagnetic ion at a temperature (Curie–Weiss θ, ions per formula unit, optional diamagnetic term). Each is converted to the SI volume susceptibility, and the log records both.
  • Shift against temperature, from any calculation. Start from an ORCA (g, ZFS and hyperfine) or CRYSTAL calculation in Simulate ▸ DFT tensors, or type in each site's diamagnetic, contact and dipolar shifts at one temperature from any code, and extend them with a Curie, Curie–Weiss or Curie + Bleaney law. Measured shifts can be fitted to δ = δdia + a/T, + b/T² or C/(T − θ), and plotted against T or 1000/T.
  • Bond pathways from DFT: see which ion was flipped. Identify Ions lists, for each spin-flip (or single-ion) calculation, the paramagnetic ion it changed, labelled as in the output (for example Mn5); type another label to correct it. Neighbour Distances plots the distances to the paramagnetic neighbours, and Suggest Shells puts shell boundaries in the gaps. Send to pNMR (CIF) passes the contributions on.

0.9.8 to 0.9.9 (6 November 2026)

SIMPSON curves and heatmaps, faster opening of large spectra, and fixes.

  • SIMPSON: a curve from one file. Simulate ▸ SIMPSON import step 5. Curve from one file (REDOR-like) plots every point of a file against x values you choose: from the file (its spectral width or MAS rate), the point number, a typed list, a list file, or a start and step. A list longer than the data is fine; a shorter one is refused.
  • SIMPSON: heatmaps of two swept quantities. Step 6. Heatmap draws a value for every combination of two quantities as colour, from a scan table (columns such as O1 O2 Re, with or without a header line, and notes above the data passed over) or from a set of FIDs with both values in each file name. Pulse shapes now show their offset sweep, with a Pulse length (shapes) box. In a notebook: nmr.SIMPSONcurve and nmr.SIMPSONplot_heatmap.
  • Large spectra open faster, and say what they are doing. A status-bar row shows each stage of a slow read (reading, removing the digital filter, each Fourier transform) with a Cancel button. An experiment that takes more than 2 s to read is kept as a copy, so it opens in about a second next time (an 800 MHz EXSY of 256 MB: 14 s, then 1.3 s). The copy is used only when every file of the experiment and the reading options are unchanged. Settings ▸ Data turns this off, sets how much room the copies may use (5 GB by default) and clears them. In a notebook: nmr.load_cached.
  • Czjzek: the spectrum on its own. Simulate ▸ Czjzek distribution has a Show box; Spectrum only is now the default, and the distribution map is one choice away.
  • Baseline correction keeps your view. Turning on or changing a baseline no longer rescales the plot: if you had zoomed in on the intensity, the same part of the trace stays in view.
  • File ▸ Clear All History no longer crashes on Windows.

0.9.7 to 0.9.8 (2 November 2026)

Weak and strong J-coupling on one spectrum, relaxation integrals from a series of slices, and fixes.

  • Weak, strong or both in Simulate ▸ Solution NMR. The Model box now offers First order: sites and coupling groups, Spin system: exact, with strong coupling and Mixed: weak and strong sets together. In Mixed you enter the weak sites (shift, coupling groups, relative intensity) and the strongly coupled spins with the J between them, and both are drawn on one spectrum with the same area scale, so integrals are the numbers of nuclei. Spins with no coupling between them are solved as separate sets, which is exact and much faster than one large system, so an AB pair and an ABX can sit beside an ethyl group. In a notebook: opennmr.notebook.mixed_j_spectrum. See Simulate.
  • T1 or T2 from a series of extracted slices. After you extract a slice from a pseudo-2D spectrum and keep it, Integrate ▸ Integration Regions shows Integrate all N slices of … with these regions. It integrates every slice of the series with the regions you set on this one, so Export Integration to Pseudo-2D… is available for curve fitting. Previously it stayed greyed out. See Integrate.
  • Changing the nucleus now updates pseudo-2D spectra. Right-clicking a spectrum to set the nucleus (for example from 500 MHz to 100 MHz) changed the 1D spectra but left pseudo-2D spectra on the old axis; both now follow. The right-click menu also offers the nucleus suggested by the acquisition parameters directly.
  • Czjzek distribution works in the installed apps. A data file that scipy needs was missing from the installers, so the module failed on opening. The installers now include it, and the built-in self-test checks it.
  • Fonts. The font lists in Plot Style no longer offer novelty typefaces (Jokerman and the like); a font you saved earlier is still used. Axis labels with ∥ and ⊥ no longer warn about a missing glyph, and a subscript such as T1 in a regularisation plot title is drawn correctly.

0.9.6 to 0.9.7 (1 November 2026)

Choose the powder average, know how long a run will take, and a steadier app.

  • Powder averaging is back in Solid-state NMR (Simulate and Fit ▸ Solid-state NMR, and Multi-spectrum fit, under Orientations): Automatic, ZCW, Lebedev or Rectangular (θ/φ). Automatic uses ZCW for a static pattern; under MAS it uses Lebedev for a peak without a quadrupolar interaction and ZCW for a peak with one. Measured against a converged average, Lebedev makes MAS sidebands of a CSA about 15 times more accurate with an eighth of the orientations, but makes a second-order quadrupolar MAS lineshape with narrow lines about 40 times less accurate than ZCW: that lineshape still has sharp edges. The log says which scheme each peak used, and Copy as Python includes it (powder_scheme=).
  • How long will it take? Before a Solid-state NMR simulation or fit starts, openNMR estimates its run time from a quick trial run. A simulation over 10 s, or a fit that could take over a minute, asks first, with what would make it faster; quick runs start at once. The report says how long the run took next to the estimate. In a notebook: opennmr.notebook.run_time.estimate_simulation_time and estimate_fit_time.
  • Instant font size and colour scheme (Settings ▸ Interface): each change now takes a fraction of a second instead of several seconds. What is on screen updates at once; everything else updates when you next see it.
  • Crash log. If something unexpected goes wrong, openNMR says so and writes the details to crash.log (Help ▸ Open Crash Log Folder). The installed apps have no console, so these errors used to vanish. Please send that file with a note of what you were doing when you report a problem.
  • Settings are saved safely. Your settings, plot styles, probe settings and DFT calibration library are written to a temporary file first and then swapped in, so a crash or power cut while saving can no longer leave a half-written file that resets everything to the defaults.

0.9.5 to 0.9.6 (31 October 2026)

Find anything with a search, a shortcut sheet, a start-up screen, and a notebook for each experiment.

  • “Where is…?” search (Help ▸ Search Commands…, Ctrl+H; on a Mac, Control+H, because Cmd+H is the system's Hide): type a few letters of what you want, such as baseline, export png or T1, and choose from every menu action, panel, section and labelled control. Choosing a control takes you to it: the panel switches, the sections around it open, and the control is outlined for a moment. Choosing a menu action runs it. Notebook functions are listed too; choosing one copies its name. The search is built from the window itself, so new features appear in it automatically. See Find a control or a command.
  • Keyboard shortcut sheet (Help ▸ Keyboard Shortcuts…, F1): every shortcut in one searchable list, copied as Markdown if you want a cheat sheet. It is generated from the menus, and warns if two actions ever share a key.
  • Export an experiment to a notebook (File ▸ Export Experiment to Notebook…): writes a Jupyter notebook that re-reads the selected experiment with the same reader settings (window, zero-fill, truncation, linear prediction, phase) and plots it. Baseline correction, referencing, drift correction and fit results are listed in the notebook with their values but not re-run, so check that list before comparing the notebook's spectrum with a figure from the app. In a notebook, use export_experiment_notebook. See Export an experiment to a notebook.
  • Start-up screen and one window. The apps show a splash screen with the version while they load, instead of nothing for several seconds. Starting openNMR again while it is open brings the existing window forward rather than opening a second copy (use --new-instance if you want several).

0.9.4 to 0.9.5 (30 October 2026)

Exact axis limits, a check for truncation wiggles, and Bruker first-point scaling.

  • Type the axis limits (Plot Style ▸ Axis limits): frame a 1D spectrum, a Compare stack or overlay, or a 2D contour to an exact range, in the unit the axis shows (ppm, Hz, kHz or mm). The order does not matter, the plot keeps its direction (ppm still runs high to low), and you can leave a box empty, or fill in one end only. The range is used for the saved figure too; Reset to full view removes it. See Plot style.
  • Check for truncation wiggles (Process ▸ Direct dimension): if the FID is cut off before it has decayed, the transform carries sinc wiggles beside strong lines that look like a multiplet and are not in the sample. The button measures how large they are and how far apart, says whether the window TopSpin recorded could be reproduced here, and offers the sine-bell that removes them with the least broadening. In a notebook, use check_f2_ringing. See Process.
  • Bruker first-point scaling (FCOR). TopSpin multiplies the first point of the FID by FCOR before the window and the transform, in both dimensions. openNMR now does the same when it reads Bruker data, so the baseline of a 1D spectrum, and the t1 noise of a strong 2D spectrum, match TopSpin. Data without an FCOR value are unchanged.
  • Fixed: saving SVG, PDF and EPS from the installed app. The Windows, macOS and Linux apps could save PNG figures but failed on the vector formats with “No module named matplotlib.backends.backend_svg”. All of them now work, and the installers are checked for this before release.

0.9.3 to 0.9.4 (28 October 2026)

Compare shows true intensities, with spacing and mixed panels.

  • True relative intensity in Compare. Each stacked spectrum used to be scaled to its own tallest point inside the plotted range, so differences in intensity between spectra were hidden. They now share one scale, as in TopSpin (Same intensity scale for all, on by default), and the Normalize list has a new Unscaled (as recorded) choice that applies no scaling at all. See Compare.
  • Spacing slider (Compare ▸ Spacing): drag to move all stacked spectra apart or together at an even spacing, down to overlapping. Zooming and scrolling are kept as you drag.
  • 1D, 2D and pulse sequences together. Tick spectra of different kinds and Compare puts each in its own panel of one figure.
  • Panel labels (Compare ▸ Panel labels): letters or numbers, with the style, order, start, size and position you choose. Drag any label on the plot to move it, singly or all together.
  • Shaped pulses in the pulse-sequence viewer can be drawn rounded (as before), as a rectangle crossed by a diagonal arrow, or as a rectangle with a diagonal and one half shaded.
  • Fixed: slices cut off at the top. In a 2D contour plot with extracted slices, the top slice or slices could be clipped, partly or wholly, when the spacing was tight. The slice panel now always fits every slice.

0.9.0 to 0.9.2 (27 October 2026)

DFT tensors on the crystal structure, a figure preview before saving, and more control over legends.

  • Tensors on the structure (Simulate ▸ DFT tensors): draw the calculated shift, shift-anisotropy or EFG tensors centred on their atoms in the unit cell or molecule, so you can see how each is oriented relative to the bonds. Show one site or every site, all to one scale, with the atoms in a radius around them, or any fractional range or supercell (for example a from −0.2 to 1.6, or 2 × 2 × 1). See Simulate.
  • A clearer DFT section. It now runs as six numbered, collapsible steps: the calculation and sites, the shift scale (or paramagnetic scaling), solid or solution and motional averaging, the experiment, simulate, and view the tensors. The nucleus is taken from the sites you chose, so it is no longer typed twice.
  • Tensor Plot Style (right-click a tensor picture) has new Axes & Labels and Atoms & Bonds tabs: hide or pad the x, y, z tick labels and axis labels, or hide the box altogether; and set the atoms' size, opacity, outline, depth cueing and colours (element by element), and the bonds' width and colour.
  • Move the legend, and give it columns (Plot Style ▸ Legend, on every plot): more positions, outside right (the plot makes room for it), or a custom place, inside or outside the axes; and any number of columns. See Plot style.
  • See a figure before you save it. Save (Ctrl/Cmd+S) first shows the figure exactly as it will be written, at the export size, and lets you change the width, height and DPI and keep them for later exports.
  • Compare: Remove, Clear and the Delete key take spectra out of the comparison entirely, and they stay out when you change the selection in Open experiments. The plot controls are grouped in one collapsible Compare Controls section.

0.8.0 to 0.8.3 (24 to 25 October 2026)

Installers, and a closer look at paramagnetic and shifting-echo data.

  • Installers for Windows, macOS and Linux. openNMR can now be installed as an ordinary app, with no Python needed. See Download. The pip package is unchanged and remains the way to use openNMR in a notebook.
  • CRYSTAL calculations (Simulate ▸ DFT tensors): read CRYSTAL output for the hyperfine (Fermi contact and spin-dipolar) shifts and the electric field gradient of paramagnetic materials. You supply the magnetic scaling as a spin polarisation factor, a susceptibility, or a Curie–Weiss θ with μeff, and openNMR returns shifts, CSA and quadrupolar parameters ready to simulate. See Simulate.
  • Shifting-p and shifting-d echo (Advanced processing ▸ Shearing and Scaling): new presets that shear the data so the shift and the first-order quadrupolar pattern separate into the two dimensions. The projections can be shown as a sum or a maximum, and the Shear preview now has projections of its own. See Advanced processing.
  • Colour themes: Gruvbox (light and dark), Dracula and Forest join the existing themes in Settings ▸ Interface.
  • The Install button in Settings ▸ Updates is no longer offered for a release that has no installer.

0.7.0 to 0.7.4 (23 to 24 October 2026)

Solution and solid-state fitting, insets, and field-drift correction.

  • Fit sections renamed. The Fit tool now has Solution NMR and Solid-state NMR sections (the latter is the old CSA, Quad & J-coupling). J-coupling can now be put on isotropic peaks. Strongly coupled spin systems (roofing, AB, ABX) can be fitted exactly from Solution NMR as well as from Solid-state NMR, and Simulate gains a matching Solution NMR section. See Fit and Simulate.
  • Inset on any plot. Click Inset in the plot toolbar (or press Ctrl+I, Cmd+I on macOS) and drag a box to magnify that region in a corner of the figure, with optional connector lines, frame, font and axis labels. It works on 1D spectra, 2D contour plots, curves and the Compare view, and is kept when you export the figure at full resolution.
  • Integral labels (Integrate): show “∫ = 1.00” above each integration region, with the smallest integral set to 1, and control the size, colour, font, height and angle. Select-and-integrate-from-plot moved to Ctrl+Shift+I.
  • Field drift along the slices (Process): track a peak through a series of slices, fit the drift with a line, a polynomial, a smoothing spline, a spline through chosen slices or a sinusoid, and apply or remove the correction. It works for data from any instrument. The fitted drift is saved with the spectrum.
  • Better automatic phasing. A rolling baseline hump no longer pulls the phase 15 to 48 degrees off, and weak slices of a 2D are phased by interpolating between good ones.
  • Import tables. CSV, plain x y text and JCAMP-DX files written by Export Data (or by hand) can be opened again as spectra or FIDs, 2D matrices included. See Open.
  • Dynamics was reorganised, with every section folded to start. Start + step series gained a Step multiplier, so a start of 0.1, a step of 0.1 and a multiplier of 2 gives 0.1, 0.2, 0.4, 0.8. See Dynamics.
  • Welcome tour: a new “Type of work” page pre-selects sensible options. The tool order in the toolbar is now Open, Process, Integrate, Fit, Dynamics, Simulate, Compare, Advanced processing, Apply, Settings.
  • DFT: solid or solution state for calculated tensors, averaging of sites with a clearer layout, and more colour options for plots.

0.6.0 (23 October 2026)

SIMPSON simulations, and exporting your data.

  • Export Data (File ▸ Export Data…): any spectrum, from any instrument, to CSV, plain x y text or JCAMP-DX, as the spectrum or as the FID exactly as acquired. See Export your data.
  • SIMPSON import (Simulate): SIMPSON spectra, FIDs, scan tables, pulse shapes and input scripts. FIDs stay live in Process, and the first points of many FIDs can be combined into a curve against a quantity you choose. See Simulate.
  • SIMPSON spectrum fit (Fit): fit a measured spectrum with one or more SIMPSON simulations as templates, with optional shift and broadening per template. See Fit.
  • Welcome tour: now also sets the crosshair colour and width, the zoom-box width, automatic default plot styles, the extra axis lines on curve plots, and the start-up update check.
  • The same functions are available in a notebook (import opennmr.notebook as nmr); the SIMPSON panels have a Copy notebook code button.

0.5.0 to 0.5.5 (22 October 2026)

  • Compare: column, row and grid panel layouts.
  • Figures: an exported-figure resolution (DPI) bug is fixed, widths are kept when exporting, and there are zoom-box width controls, labels for names over traces with adjustable height, and a wider Plot Style window.
  • Pulse sequences: the viewer names delays on the pulse line, no longer shows housekeeping elements, keeps loop labels from being cut off, and its plot can be customised.
  • Varian: the ppm axis was wrong (the transmitter offset was subtracted twice), and data converted with vconv were shown mirrored. Both are fixed, so spectra opened in earlier versions may have shown shifts that were off: reopen them.
  • X-Pulse: a default 1 Hz offset that should not have been applied is removed.

The full history is in the commit log.
