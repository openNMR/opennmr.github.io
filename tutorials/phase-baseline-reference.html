Phase, baseline and reference a 1D spectrum

From a raw FID to a phased, flat, referenced spectrum, using solid KBr.

Data used here: 79Br of solid KBr, 500 MHz spectrometer, 1.3 mm rotor under MAS (Bruker, raw FID). Any 1D Bruker, X-Pulse, Varian, JEOL or Spinsolve experiment works the same way.

Load the raw FID

Follow Open your first spectrum to load the experiment. openNMR reads the raw FID and does the Fourier transform itself, so you see the spectrum in the Processing Preview tab together with its FID, and every step below changes what you see there straight away. A spectrum that was processed in another program (TopSpin’s 1r data, say) is a different starting point: its phase and baseline were set there.

Select the Process tool. Its sections, from top to bottom, are the order of a normal workflow: FID Processing, Phase, Baseline, Reference, Field Drift Correction. For this spectrum we leave FID Processing at its defaults.

Phase

  1. Open the Phase section.
  2. Click Autophase. It searches for the zero-order phase that maximises the integral of the real part. Phase 1 stays at zero unless you tick 1st-order.
  3. Look at the result. In our run Autophase changed Phase 0 by 16.2°. If a line still has a dispersive foot, adjust Phase 0 by hand with its handle, or step it with the ±90° / 180° buttons. Revert Autophase puts back what you had before.

Check it by eye. Autophase maximises an integral, and a rolling baseline also changes that integral. If the baseline is badly distorted, phase first, correct the baseline, then re-check the phase.

Correct the baseline

Open Baseline and click Baseline Correct. The default method is a straight line fitted to the edges of the spectrum, with a sigma-clip so that real peaks do not bias it. The other methods (polynomial, sinusoidal, spline, automatic-point spline, Whittaker) are in the Baseline method menu, and the fitted coefficients can be nudged by hand. The preview draws the baseline as a dashed line, so you can judge it before you rely on it.

Spinning sidebands of a quadrupolar nucleus sit far from the centreband. If a signal reaches the spectral edge, the app says so in the status bar. In that case choose a method that does not take its points from the edges (Whittaker, or the automatic-point spline), or name Baseline regions yourself.

Reference the shift axis

The ppm axis starts out relative to whatever the spectrometer’s zero was. To fix it, find the position of a line whose shift you know and move that line to its value.

  1. Switch the pointer to Crosshair above the plot and read the position of the KBr line. Ours sits at +111.358 ppm.
  2. Open Reference. The reference shift SR is in Hz: SR = −(position in ppm × ν0 in MHz). For this spectrum ν0 = 125.3 MHz, so SR = −13953.43 Hz. Type it into SR (direct).
  3. Click Apply Reference Shift. The line is now at 0 ppm.

Here the KBr line is set to 0 ppm, which is how solid KBr is commonly used as a 79Br shift standard. Whatever reference you choose, say so in the figure caption or the methods: a shift without a reference is not a number someone else can use. If you have referenced one nucleus, SR from Another Nucleus converts that SR to another nucleus on the same field.

If you change your mind

Every processing step can be undone with Edit ▸ Undo Last Processing Change, so try things freely.

Do not fit an anisotropy to this spectrum. KBr is cubic: its chemical-shift anisotropy is zero by symmetry, and the sideband manifold of 79Br is used to set the magic angle, not to measure a tensor. A fit of a CSA to it would converge to something (the app will report a poor R² and warn about it), but it would not mean anything. The next tutorial fits a real CSA.
