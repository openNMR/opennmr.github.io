Install openNMR

Install with one pip command and start the app. This takes a few minutes.

What you need

openNMR runs on Windows, macOS and Linux. You need Python 3.12 or newer. Everything else, including the graphical interface, comes with the package, so there are no extras to choose between.

Install

  1. Open a terminal (Command Prompt or PowerShell on Windows, Terminal on macOS and Linux).
  2. We recommend a separate environment, so openNMR cannot disturb your other Python work. Create and activate one: 
    # Windows
py -3.12 -m venv opennmr-env
opennmr-env\Scripts\activate

# macOS / Linux
python3 -m venv opennmr-env
source opennmr-env/bin/activate
    If you use conda, conda create -n opennmr python=3.12 followed by conda activate opennmr does the same job.
  3. Install openNMR from PyPI: 
    pip install opennmr
  4. Start the app: 
    opennmr-gui
    The openNMR window opens on the Open tool. Continue with Open your first spectrum.

You will need to activate the environment again (the activate line above) each time you open a new terminal, before running opennmr-gui.

Use it in a notebook

The same package works in Jupyter and Google Colab, so everything you do in the app can also be scripted:

from opennmr import notebook as nmr

Keep it up to date

Open Settings and look under Updates. It shows the installed version and checks PyPI when you press Check for Updates. A check at start-up is off unless you turn it on. If a newer version exists, Update to X and restart closes openNMR, upgrades it in the same environment and opens it again. If the new version fails to start, the old one is put back.

To update by hand instead: pip install --upgrade opennmr.

Add an openNMR button to TopSpin

If you use Bruker TopSpin, one command adds a button that launches openNMR from TopSpin's toolbar:

opennmr-topspin-install

It finds your TopSpin installations and asks before copying anything. Run it from the same environment you installed openNMR into, because the button remembers that environment's location. If you later move or recreate the environment, run the installer again. Writing into TopSpin's own folder may need administrator rights. opennmr-topspin-install --uninstall removes it again.

Troubleshooting

pip or py not found
Python is not installed, or is not on your PATH. Install Python 3.12 or newer from python.org (on Windows, tick “Add python.exe to PATH”) and open a new terminal.
“No matching distribution”
Your Python is older than 3.12. Check with python --version.
opennmr-gui not found
The environment is not active in this terminal. Activate it and try again.
Anything else
Report a problem with the output of pip show opennmr and the text of the error.
