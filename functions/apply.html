What it does

Apply holds methods built around a specific kind of experiment rather than a general step in the workflow. At present there are two sections:

  • eNMR measures electrophoretic mobility by fitting the phase of a resonance against the applied voltage.
  • Imaging turns the spectrum's frequency axis into a real position axis (in mm) once you tell openNMR the gradient strength, and supports T2 measurement by integration across an imaging series.

Before you start

Load an experiment with Open and select it. For eNMR, process the spectrum first. For imaging, you need to know the maximum gradient of your probe.

How to use it

eNMR

  1. Click Apply in the toolbar and open eNMR. The voltages are read from the experiment's vdlist.
  2. Under Resonance, give the From and To shifts that bracket the peak you want to follow.
  3. Under Cell and sequence, enter the Electrode gap and set the Cell polarity (which way the positive electrode faces relative to the gradient). The polarity is the one thing no file records, so check it against your cell's wiring.
  4. Click Fit eNMR. Within one experiment the +V/−V pairs are differenced, which cancels every phase error that is not driven by the field.
  5. The experiment is usually run twice with the gradients reversed. Click Keep as repeat after each, then Combine repeats. The spread across repeats is reported with the result.

Imaging

  1. Open Imaging and enter the Max gradient and the Gradient axis (z, x or y) the experiment used.
  2. Right-click the Spectrum plot and choose Axis Units ▸ mm. The frequency axis becomes a position axis.
  3. Click Save as default for this probe so any other experiment recorded with the same probe uses the same value automatically.

Options and controls

Voltages: Zero at / Scale / Fit up to
How the recorded voltage list is interpreted and how much of it is used in the fit.
Unfold ±V
A vdlist records each voltage magnitude twice, at opposite polarity, so the recorded axis folds every point onto its partner (0, 0, 8, 8, 16, 16…). Unfolding gives the first of each pair +|V| and the second −|V| and plots the ramp through zero.
Keep as repeat / Combine repeats / Clear
Set a fit aside as one of the gradient-reversed repeats, average the kept repeats (aligning their signs first, since reversing the gradient flips the slope), or start again.
Max gradient / Gradient axis / Gradient used
One maximum is kept for each axis of a probe, because the three coils of a triple-axis probe are rarely equally strong. Using one number for all three would quietly scale every position or diffusion coefficient measured on the others.

Tips and troubleshooting

  • Two repeats should agree. The result reports their spread. If two runs of one sample disagree by more than the uncertainty, suspect the phase, the polarity or sample movement.
  • The mm axis is greyed out. Select a spectrum first; the controls need one.
  • Is a section missing? Sections you do not use can be hidden in the app's settings, and brought back the same way.
