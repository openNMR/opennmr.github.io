Process

Process turns the raw FID from your experiment into a spectrum you are ready to analyse: apodise, zero-fill, phase, correct the baseline and reference the shift axis, with a live preview of every choice.

What it does

An experiment is recorded as a free induction decay (FID). Process is where you turn it into the spectrum you will fit, integrate or plot: you choose the window function and zero-filling, fix the phase, remove the baseline and set the ppm reference. Every control is live. Change one and the preview redraws, so you see what a choice does before you commit to it.

Nothing here changes your raw data. Reset (in FID Processing) discards every choice and returns the spectrum to exactly how it looked when it was first loaded.

Before you start

Load an experiment with Open and select it in the Open experiments list. If you have loaded several, Process works on the selected one.

How to use it

  1. Click Process in the toolbar. The plot switches to a live preview of the FID and the spectrum side by side.
  2. Open FID Processing. Pick a Window (and its Line broadening), a Zero-fill to size, and, if you need them, Truncate to, FID shift or linear prediction. The defaults are a sensible place to start.
  3. Open Phase. Click Autophase for a first guess, then adjust Phase 0 and Phase 1 by dragging or typing until every peak is flat and upright.
  4. Open Baseline. Choose a Baseline method, tick Show baseline on the plot to check it runs under the peaks, then click Baseline Correct.
  5. Open Reference. Type the SR (spectrometer reference, in Hz) that puts a known peak at its right ppm and click Apply Reference Shift.

The spectrum you see in the Spectrum tab is the processed result, ready for Fit, Integrate or Compare.

Options and controls

FID Processing

Preview / FID x-axis
How the FID is drawn in the preview (Real, Magnitude, or Real + Imaginary; time or points). Display only; it does not change the result.
Window
The apodisation applied to the FID, with its Line broadening, Gaussian broadening or Sine-bell shift (SSB) where the window uses them.
Zero-fill to
The FFT size. None leaves the FID as acquired; the default is the nearest standard size at or above the acquired points. Custom size accepts any value.
Truncate to
Keeps only the first points of the FID, for example to discard a noisy tail.
Align Echo / Echo position
For full-echo acquisitions (rising then falling) rather than a one-sided decay: rolls the FID so the echo peak sits at t = 0 before windowing.
FID shift
Shifts the FID in points before the transform.
Linear-predict points / LP order / LP direction
Extends the FID forward past its end, or reconstructs points lost before its start (Backward).
Magnitude Mode
Shows |real + imaginary| so every peak is positive and no phasing is needed. The phase controls switch off while it is on.
Process Indirect Dimension
For 2D data. A relaxation or diffusion series (pseudo-2D) is the default and needs no transform along F1. Click this only for a genuine 2D correlation experiment (COSY or HSQC style). The F1 controls (truncate, zero-fill, window, F1 LB, F1 SSB) are set separately from the direct dimension.
Reset
Discards every live processing choice and returns to the spectrum as first loaded.

Phase

Autophase
Searches for the phase that makes the spectrum most absorptive. Zero-order only unless 1st-order is ticked; the first-order term is kept only if it demonstrably improves the lineshape.
Revert Autophase
Undoes the last Autophase, in case the automatic result was worse than what you had.
Phase 0 / Phase 1 / Pivot
The total phase applied right now, in degrees. Drag the handle or type a value. Pivot is the position that stays fixed when Phase 1 changes.
Quick phase (180°, +90°, −90°)
Nudges Phase 0 by a fixed amount. Useful for a spectrum that is upside down.
Zero Phase 0 / Zero Phase 1 / Reset
Clear one or both terms.
Slice, ◀ ▶, Apply to every slice, Each slice independently
For a pseudo-2D series. Phase one slice at a time, apply the same phase to all of them, or let Autophase find a separate phase for every slice.
Dimension
For a 2D, whether the phase is applied along the direct (F2) or indirect (F1) dimension.

Baseline

Baseline method
Linear, Polynomial, Sinusoidal, Spline (with automatic points, points chosen on the plot, or a smoothing spline) or Whittaker, plus manual models whose coefficients you can set.
Baseline regions
Tell the fit where the spectrum really is baseline: type ppm ranges, or tick Pick on plot and drag across the preview.
Pick points on plot / Start from automatic
For the spline: click where the baseline is, or start from the automatic points and move, add or remove them.
Show baseline on the plot
Draws the baseline that would be subtracted, before you commit to it.
Baseline Correct
Subtracts the baseline from the spectrum (or from the selected slice, or every slice when Apply to every slice is ticked).

Reference

SR (direct) / SR (indirect)
The reference offset, in Hz, for each dimension. Apply Reference Shift applies it.
SR from Another Nucleus
A field offset moves every nucleus by the same ppm, so an SR measured on one nucleus gives the SR of another: SRnew = (SRcal / SFO1cal) × SFO1new. Pick the calibrated experiment (or type the values) and click Apply to This Spectrum.

Field Drift Correction

Measure Start and End Shifts
Using 1D spectra of the same peak recorded just before and just after a long 2D, 3D or 4D experiment, measures how far the field drifted.
Start shift / End shift
The drift in Hz at the start and end, assumed linear in time. Type them if you already know them.
Apply to Selected Spectrum / Remove Correction
Reprocesses the selected Bruker 2D or pseudo-2D from its raw FIDs with the correction, or undoes it.
Write Corrected Bruker Dataset… / Concatenate NUS Blocks…
Write a corrected copy of a Bruker experiment to a new experiment number (the original is untouched), or join NUS blocks into one.

Tips and troubleshooting

  • Check the baseline before committing. Every baseline estimator fails the same way: by running through the feet of the peaks instead of under them. Show baseline on the plot lets you see that before it is subtracted, and baseline regions that avoid the peaks fix most problems.
  • Spectrum upside down? Use 180° in Quick phase rather than hunting with the handle.
  • Phase and baseline for series. For a relaxation or diffusion series, phase and baseline-correct in absorption mode first. Later analysis depends on it.
  • SR from another nucleus is only valid for spectra recorded on the same magnet at a similar time, with no re-shim, field or lock change, probe change or quench in between.
  • Fit the raw FIDs of a long 2D? If the field drifted during the experiment, correct for it here first (Field Drift Correction), against one reference, before adding experiments together.
