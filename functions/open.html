Open

Open is where every openNMR session starts. Point it at the folder that holds your experiments, pick the ones you want, and load them into the viewer.

The Open screen

Everything you need is in the left-hand panel. The top half browses your folders, and the bottom half lists the experiments you have loaded. Whatever you load is shown in the viewer on the right.

Load a spectrum

  1. Click Open in the toolbar. It is highlighted blue while it is active.
  2. Under Browse a folder, click Choose Folder… and select the folder that contains your experiments. The path is shown underneath, and the experiments found there are listed, with a count at the bottom of the list.
  3. To load a single experiment, double-click it. To load several at once, Ctrl-click or Shift-click to select them, then click Open Selected. That button is greyed out until something is selected.
  4. Your experiments appear under Open experiments, and the data is drawn in the viewer.

Each entry in the list is a sample folder, with a small arrow beside it. Click the arrow to expand it into the numbered experiments it contains. Each experiment is listed with its number, the observed nucleus, whether it is 1D or 2D, the number of points and the pulse programme, for example 3 · 1H, 1D, 262144, hahnecho3.enb.

Supported data

openNMR reads raw acquisition data (the FID, or the series of FIDs), never a vendor's own pre-processed spectrum, and turns every format into the same internal spectrum object. Everything after loading therefore works identically whichever instrument the data came from.

Bruker
TopSpin experiments (fid for 1D, ser for 2D and pseudo-2D), including diffusion series.
X-Pulse
JCAMP-DX FIDs, including arrayed and pulsed-field-gradient experiments.
Varian / Agilent
fid with its procpar.
JEOL Delta
.jdf files. One-dimensional data only so far.
Magritek Spinsolve
Spinsolve experiment folders.
SIMPSON (simulation output)
Text spectra and FIDs written by SIMPSON (.spe, .csdf, .fid) and headerless x re im .dat files. These are recognised from their content, and binary SIMPSON files are refused with a message. They are loaded and plotted from Simulate ▸ SIMPSON import, and can be fitted to a measured spectrum in Fit ▸ SIMPSON spectrum. They are simulated, not measured, so they carry no field or nucleus until you say which.

Point Choose Folder… at the folder that contains your experiments and openNMR lists those it recognises.

Manage open experiments

Every experiment you have loaded is listed under Open experiments.

Remove
Takes the selected experiment out of the list. Your data on disk are not touched.
Clear All
Empties the list so you can start again.
Hide open experiments
Collapses the list to give the folder browser more room. Click it again to bring the list back.
Selected spectrum
A collapsible summary of the selected spectrum (empty until you select one). For a pseudo-2D series it also has a View choice: Contour, Stacked slices (every slice as an offset 1D stack) or Heatmap.

Look at your data

Tabs above the plot switch the view: the FID, the Spectrum and the Spectral Fit. Other tabs, such as the live processing preview, the comparison and the simulation, appear when you use the tool that makes them.

The buttons above the plot move you around it:

Home
Resets the view to show the whole spectrum.
Back / Forward
Step through your previous views.
Pan
Drag the spectrum around.
Zoom
Drag a box around the region you want to look at.
Save
Saves the figure; the file dialog lists the image formats available. To save the spectrum itself, use File ▸ Export Data…. To save the numbers a tool produced, use the export buttons in that tool (for example Fit or Integrate).

The three buttons at the top right of the plot change what the cursor does:

Crosshair
Shows a cross that follows the cursor across the plot (and across both projection strips on a 2D). Ctrl+. toggles it. Right-click the button for its colour and line width.
Measure
Click two points and the distance between them is labelled in ppm and Hz at once. Ctrl+D toggles it from anywhere.
Width
Click a peak and its full width at half maximum is drawn and given in ppm and Hz (along both axes on a 2D). Where peaks overlap the value is marked as an estimate, so fit the peaks for a reliable width. Ctrl+L toggles it from anywhere.

The Title / notes tab at the right edge of the window opens a panel for naming and annotating the selected experiment. What you write is saved with the experiment (for Bruker data, in its title file), and the first line appears as a tooltip on the experiment's entry in Open experiments, so you can tell similar experiments apart.

Export your data

File ▸ Export Data… (Ctrl/Cmd+Shift+X) writes any spectrum in Open experiments, whatever instrument it came from, to a plain file that other programs read. Tick the spectra you want and press Export…; each is written to its own file.

Format
CSV table (.csv), plain x y text (.xy) or JCAMP-DX (.jdx).
Write
The spectrum, or the FID as acquired: against time in seconds, exactly as read, before any window or zero-fill. The FID is available only for spectra that came from one.
x axis
The format's default (ppm; Hz for JCAMP-DX), or ppm, or Hz.
Imaginary part
The format's default (written to CSV only), always included, or the real part only.
2D row
For a 2D or pseudo-2D spectrum, which row to write. For CSV you can instead tick 2D: write the whole matrix.
Lowest x first
Writes the points in ascending order of x, instead of the plot's order.

Settings

The Settings tool, at the right of the toolbar, adjusts openNMR to the way you work. Its sections:

Interface
Menu font size, light or dark appearance (or follow the system), the crosshair colour and width, the units used for export size, and what clicking, dragging and double-clicking do on a plot.
Fitting
The maximum number of fit iterations.
Sections shown
Hide the sections you never use (for example eNMR, Imaging or SIMPSON import), and bring them back in the same place whenever you like. Nothing is lost.
Data
A default data folder, so every Open dialog starts there and the browser lists it at start-up, and whether Bruker data open with TopSpin's own processing parameters.
Saving
The folder where openNMR saves its states.
Default plot styles
Save the plot style you have set up as the default for each kind of plot (1D spectrum, 2D contour, pseudo-2D stack, Compare, curves and profiles, tensor pictures).
Updates
Shows the installed version. Check for Updates asks PyPI whether a newer version exists, and can install it and restart openNMR for you. A check at start-up is off unless you turn it on.

The Welcome to openNMR tour (Help ▸ Welcome to openNMR…) walks through the most useful of these settings once, in six short pages: appearance, mouse and plots, which sections to show, and data and fitting. It sets the same settings as this panel; nothing is stored twice. Since 0.6.0 it also covers the crosshair colour and width, the zoom-box width, using your saved default plot styles automatically, the extra top and right axis lines on curve plots, and whether to check for a newer version at start-up.
