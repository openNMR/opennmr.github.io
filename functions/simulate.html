Simulate

Simulate synthesises spectra from parameters you choose, so you can see what a model predicts before you fit it, or compare a calculation against your data.

What it does

Simulate is a forward calculator: you give it the physics and it gives you the spectrum. Its sections, in the order the tool lists them: Solution NMR (first-order multiplets, strongly coupled spin systems solved exactly, or both on one spectrum); Solid-state NMR, formerly CSA, Quad & J-coupling (peaks with any mix of CSA, quadrupolar and J-couplings, static or MAS); Czjzek distribution (disordered quadrupolar sites); DFT tensors (from CASTEP, VASP, ORCA, Gaussian or CRYSTAL calculations); Diffusion (PFG); Shaped pulse (Bloch); Paramagnetic NMR tools, shown when switched on (pNMR (CIF), shifts against temperature, bulk magnetic susceptibility shifts and bond pathways); and SIMPSON import. Results can be kept as spectra and compared directly with real data.

Before you start

Nothing needs to be loaded: Simulate works on its own. If a spectrum is open, simulations can use its nucleus and field, and you can keep the result next to your data in Open experiments.

How to use it

  1. Click Simulate in the toolbar and open the simulator you want, for example Solid-state NMR.
  2. Choose the Nucleus and the Larmor frequency, and the Regime: Static powder, or MAS (centreband + sidebands) with its MAS rate.
  3. Add peak for each site and give it δiso, an amount and a broadening. Then Add interaction ▾ gives the selected peak a CSA, a quadrupolar coupling or J-couplings, in any mix. A peak with no interaction is an isotropic peak.
  4. Click Simulate. The spectrum is drawn in the Simulation tab.
  5. Click Keep in Open Experiments to turn the simulation into a spectrum you can compare, fit against or export, or Send to Fit as Starting Values to start a fit from it.

Options and controls

Solution NMR

Model
First order: sites and coupling groups builds each multiplet from its coupling groups. It is exact when every shift difference is much larger than J. Spin system: exact, with strong coupling solves every spin's shift and the J between them exactly (roofing, AB, ABX, AA′BB′; up to about 12 spins). Mixed: weak and strong sets together adds both on one spectrum, for example an ethyl group beside an aromatic AB pair.
Mixed: weak sites and strong spins
Enter the weak sites (shift, coupling groups, relative intensity) in one table, and the strongly coupled spins and the J between them in the other, with one linewidth in Hz for the strong lines. Both parts use the same area scale (each observed nucleus counts 1), so relative integrals are the numbers of nuclei. Spins joined by no J are solved as separate sets, which is exact and quicker than one large system; sets without the observed nucleus are skipped. Switching model keeps what you typed. Copy notebook code gives the same calculation as mixed_j_spectrum.

Solid-state NMR

Model
Peaks with interactions (CSA, quadrupolar, J to other nuclei): any mix of interactions on each peak, static or MAS. Strongly coupled peaks (exact J between them): the exact spin-system model (roofing, AB, ABX, AA′BB′). There is one spin-system panel, shared with Solution NMR; it sits in whichever section used it last.
Nucleus, Spin I, field
The observed nucleus and the field. With a spectrum open, they can be taken from it.
Regime, MAS rate
Static powder or MAS (centreband + sidebands). Under MAS every spinning sideband is included.
Peaks (sites)
Add peak, Duplicate, Remove: one row per site, each with a Label, δiso, an Amount (relative population) and its own Broadening: Gaussian, Lorentzian or pseudo-Voigt (with its Lorentzian fraction), and the FWHM.
Add interaction ▾
Adds to the selected peak:
  • Chemical-shift anisotropy (CSA): the Convention, Haeberlen (Δ, η) or Herzfeld–Berger (span, skew), and the two values. On a peak that also has a quadrupolar coupling, the Euler angles (ZYZ) give the orientation of the CSA tensor in the EFG frame; all zero means the two coincide.
  • Quadrupolar: CQ and ηQ, at the level of theory set for the panel.
  • J-coupling: the Partner nuclide, the Number n of equivalent partners and J, as a first-order multiplet. The partner's spin and natural abundance come from the nuclide table, so a low-abundance partner gives satellites. J-coupling between peaks (strong coupling, exact)… opens the spin-system model with these peaks as its spins.
Each interaction has its own Remove.
Copy to Peaks ▾
Gives other peaks (the selected ones, or all) this peak's interactions, with or without its broadening; their δiso and amount are kept. It can also remove every interaction from the selected peaks.
Theory, Transitions
Second-order perturbation, Exact (diagonalization) or First-order only, for every quadrupolar peak; All transitions, Central transition only or Satellites only. Compare levels of theory (first, second, exact) overlays the three.
Orientations / Powder averaging
How many crystallite orientations to average over (more is slower but smoother), and how they are chosen: Automatic (the default), ZCW, Lebedev or Rectangular (θ/φ). Automatic uses ZCW for a static pattern; under MAS it uses Lebedev for a peak without a quadrupolar interaction, where it is far more accurate for the sidebands with far fewer orientations, and ZCW for a quadrupolar peak, whose MAS lineshape still has sharp edges that Lebedev's largest grid (5,810 points) is too coarse for. The log records the scheme each peak used.
Run time
A simulation estimated to take more than 10 s asks before it starts, with the estimate and what would make it faster. The report shows how long it took.
Axis
Auto: frame every site, or set the minimum, maximum and number of points yourself. Also plot each site draws each peak's own contribution under the total.
Tensor picture (3D)
Show Tensors draws the interaction tensor as a frequency surface or as an ellipsoid with axes. Drag to turn it. Right-click ▸ Tensor Plot Style… sets its colours, opacity and view (Tensors tab), and on the Axes & Labels tab can hide the tick labels, the axis labels or the whole box, or pad them away from the picture where they get in the way.
Copy as Python
The same simulation as notebook code.

Other simulators

Czjzek distribution
The powder spectrum of a site whose quadrupolar coupling is spread over a Czjzek distribution, with the distribution of (CQ, ηQ) shown beside it. Choose plain Czjzek (a random field gradient centred on zero, set by σ alone) or Extended Czjzek (a mean field gradient plus a random part). Show: Spectrum only (the default), or the spectrum with the map to its left or below it.
DFT tensors
Simulates the spectrum from a CASTEP .magres file, VASP OUTCAR, ORCA output, Gaussian log or CRYSTAL output. The section is laid out as six numbered steps; open each in turn:
  1. Calculation and sites: choose the file, the element and the observed isotope, and tick the sites to simulate. Merge equivalent sites turns identical sites into one, with their count as its amount.
  2. Shift scale (references) or paramagnetic scaling: add one or more reference calculations with their experimental shifts, and openNMR fits the shift scale (or type σref, δref and the slope). Scales can be saved and loaded again. A CRYSTAL calculation is scaled as described below instead.
  3. Solid or solution, and motional averaging: keep the tensors in full (solid) or average them to their traces (solution), and average the sites a fast motion exchanges (a rotating CH₃, say).
  4. Experiment: the field (B₀, or the ¹H frequency), static powder or MAS and the spinning rate, the transitions and the level of theory. The nucleus is the isotope chosen in step 1; it is not typed again.
  5. Simulate: Calculate Sites and Simulate, with the table of every site's parameters. The sites can then be edited by hand and simulated again (Simulate the Sites as Edited).
  6. View tensors (3D): see below.
DFT tensors: on the structure
Step 6 can show a site's tensors as an ellipsoid, a frequency surface, or On the structure: centred on their atoms in the crystal or molecule, so their orientation relative to the bonds can be seen. Show one site's tensors or every site's, all to one scale. The shift anisotropy and the EFG are drawn as ovaloids, red where positive and blue where negative (no ellipsoid can show a tensor of both signs). Atoms shown: the unit cell (or the whole molecule), every atom within a radius of the sites, or a fractional range / supercell: give the range along a, b and c (for example a from −0.2 to 1.6), or a supercell n × m × l. In a range, the tensor can be drawn on the copy nearest the middle or on every copy, and the cell edges of every whole cell, the origin cell, the outline of the range, or none. Bonds are a guide to the eye (closer than a tolerance × the sum of covalent radii). Tensor Plot Style ▸ Atoms & Bonds sets the atoms' size (by covalent radius or all the same), opacity, outline and depth cueing, a colour for each element, and the bonds' width and colour.
DFT tensors: CRYSTAL (paramagnetic)
A CRYSTAL calculation is the fully spin-polarised state, so step 2 shows Paramagnetic shift scaling (CRYSTAL), which scales its hyperfine interactions to your sample's magnetisation (reference compounds are not used). Give the scaling directly, or from a molar susceptibility and the spin, or from a Curie–Weiss θ, μeff and spin at a temperature and field (B₀ from the Larmor frequency fills the field). Choose Fermi contact, dipolar or both, and add an orbital shift. Atoms are named by element and CRYSTAL atom number (for example Na15). Only the hyperfine shift is calculated, so the orbital part must be supplied. A scaling typed in belongs to the field it was calculated for. Copy Import as Python gives the same steps for a notebook.
Diffusion (PFG)
Simulates a diffusion decay for a chosen D, gradient shape and pulse sequence (spin echo, stimulated echo, bipolar). It can compare gradient shapes or sequence types.
Shaped pulse (Bloch)
Calculates the excitation profile of a shaped pulse (Gaussian, sinc, BURP, hyperbolic secant, WURST and others) against offset, for a given power. The pulse and its profile are drawn one above the other, each with its own crosshair (their x axes, time and offset, differ); Measure gives a time in µs and an offset in Hz.

Paramagnetic NMR tools

An optional section, off until you switch it on in Settings ▸ Sections shown ▸ Paramagnetic NMR or choose Paramagnetic NMR in Help ▸ Welcome to openNMR…; the same switch shows Fit ▸ pNMR (CIF bond pathways). It holds four parts:

pNMR (CIF)
Predicts the spectrum of a paramagnetic material from a crystal structure. Load a CIF, choose the species and sites to include, and define shells of neighbours with a shift contribution for each.
Shift against temperature
Calculated shifts: take the shifts from the calculation in DFT tensors (ORCA, from its g, zero-field splitting and hyperfine couplings; or CRYSTAL, with its scaling), or type each site's δdia, δcontact and δdipolar at one temperature from any code (or paste four columns). Choose the Temperature law (Curie; Curie–Weiss with θ; or Curie + Bleaney, with the contact ∝ 1/T and the pseudocontact ∝ 1/T²) and the range, then Calculate δ(T), optionally with the contact and dipolar parts drawn separately. Measured shifts: type or paste T and δ, and Fit δ = δdia + a/T, δdia + a/T + b/T² or δdia + C/(T − θ), with δdia fixed if you know it. Plot against T, or against 1000/T, where a Curie law is a straight line.
BMS shifts: particles
The bulk magnetic susceptibility shift of a powder of paramagnetic particles. Generate a random packing (number; shape: ellipsoids, given by their semi-axes, cuboids (cubes when the sides are equal), given by their edge lengths, hexagonal prisms or tori; mean size and spread per axis, in nm, µm or mm, with a Gaussian, Lorentzian or pseudo-Voigt distribution; dense or random sequential addition, each explained when you hover over it; a seed, so the same packing can be made again), or read a LAMMPS dump file. The particles fill the Simulated region: a small cube of the powder, repeated periodically, whose side follows from the Packing fraction (or type it). It is not the container; the line under it says how big it is and warns if it is larger than the container. Both packers keep particles apart by a sphere around each, so cubes pack less densely than they could, and the result says what fraction was reached.
BMS shifts: susceptibility and grid
χ: one value, or the three principal values in each particle's own frame, in the Units you have: SI volume (dimensionless or ppm), cgs volume, cgs or SI mass (give the density of the solid itself, not a packing density), cgs or SI molar (the molar volume from the molar mass and density, or from the unit-cell volume and Z), or μeff per paramagnetic ion at a temperature (with θ, the ions per formula unit and an optional diamagnetic term). The value is converted to the SI volume susceptibility and the log records both. The grid size, a Periodic or Isolated boundary, and single or double precision set the speed.
BMS shifts: sample container
What holds the powder: its shape shifts each part of the sample differently, and its dimensions (in mm) are named for it: Rotor inner diameter and Packed length, or Tube inner diameter and Filled height. MAS rotor: 0.4, 0.7, 1.3, 1.9, 2.5, 3.2, 4.0 or 7.0 mm, which fills in a typical inner diameter (the outer one less the wall) and packed length; check them against your rotor. Include the rotor's own field adds that of its wall (zirconia by default; also diamond, sapphire, Vespel, PTFE, PEEK, Kapton or your own χ) and of the caps and spacers above and below the powder, which shift the sample most near its ends. Also a tube, a plate (side lengths and thickness) or a sphere (no macroscopic shift). For a static sample, give the angle between B₀ and the cylinder axis or plate normal (54.74° for a rotor at rest in a MAS probe, 0° for a tube in a solution probe).
BMS shifts: local interactions
Tick to give the observed nuclei a contact shift, a spin-dipolar anisotropy (δ, η and its Euler angles in the particle's frame) and a quadrupolar coupling (CQ, ηQ, Euler angles; central or all transitions; first order, second order or exact).
BMS shifts: spectrum
The nucleus (chosen from the list of NMR-active isotopes) and B₀; Static, MAS, infinitely fast or MAS with spinning sidebands (rate and sideband orders); whether the observed nuclei are inside the particles, between them, or everywhere; the line width and shape. Static and sampled spectra are averaged over orientations by Monte Carlo sampling, and the report gives the sampling noise; raise Samples if it is not small. Simulate keeps the field, so changing only the sample, the local interactions or the spectrum settings does not recalculate it. A run expected to take more than 10 s asks first, with what would make it faster. Show: the Spectrum, a Field slice (xz, yz or xy; δzz or δiso) or the Packing (3-D), from the last run. The report under it gives the particles, volume fraction and grid, the shift's mean, standard deviation and Gaussian FWHM as one row, then the susceptibility, the local interactions, the run time and any warnings. Keep in Open Experiments adds the spectrum to your data, with the settings in its history; Copy as Python gives the notebook code (nmr.fast_bms_spectrum).
Bond pathways from DFT
The shift contribution P of each paramagnetic neighbour, per shell and species, for pNMR (CIF). Method: a ferromagnetic reference plus one calculation per flipped ion (P = (δFM − δflip)/2), or one paramagnetic ion per calculation (P = δ). Add the calculations, then Identify Ions to see which ion each one flipped, labelled as in the output (for example Mn5); type another label to correct it. Neighbour Distances plots the distances to the paramagnetic neighbours, and Suggest Shells puts the shell boundaries in the gaps between them. Magnetic scaling: CRYSTAL (θ, μeff and S; χM and S; or φ) or ORCA (the calculated spin Hamiltonian at T). Calculate, Plot, then Send to pNMR (CIF).

SIMPSON import

Brings the output of a SIMPSON simulation into openNMR, in six steps. 1. SIMPSON files: add the files (Add files…). 2. Spectrometer: say what the file holds (spectrum or FID; the default is to detect it), the nuclide and the field (or the ¹H frequency), so the axis can be in ppm; with no nuclide the axis stays in Hz. 3. Spectra and FIDs: Plot them, or Add to Open experiments to process, compare and fit them like measured data. An FID is transformed here and stays an FID, so the window, zero-filling and phase act on it live. A file that holds several spectra or FIDs (NELEM > 1) offers an Element to plot. Send to Fit sends a spectrum on to Fit ▸ SIMPSON spectrum. 4. Points from FIDs: reads the first points of every file (A = first point, B = second, …) and plots them, or an expression such as A + B - 0.3*C, against a quantity you name (the number in each file name, a start and step, or values you type). Plot points, Save table (CSV)… or Copy notebook code for the same calculation in a notebook. Scan tables (a file of x, y and z columns) are drawn as a map or as lines, and .tcl input scripts fill in the nuclide and field boxes without being run. Pulse shapes are drawn with their offset sweep, as rows sharing one time axis: the crosshair's vertical line runs through every row, so the amplitude, phase and offset at one moment can be read together. Give the Pulse length (shapes) if the file name does not hold it.

5. Curve from one file (REDOR-like): every point of one file against x values from the file (its spectral width or MAS rate), the point number, a typed list, a list file, or a start and step; a list longer than the data is fine, a shorter one is refused. 6. Heatmap (two swept quantities): a value for every combination of two quantities, as colour, from a scan table (columns such as O1 O2 Re; the header line and any notes above the data are found automatically, or set Lines to skip and First row) or from FIDs with both values in each file name.

Tips and troubleshooting

  • Which quadrupolar method? First order is fast but only right when CQ is small compared with the Larmor frequency. Use Compare levels of theory (first, second, exact) to see where first order, second order and exact diagonalisation part company for your parameters.
  • MAS sidebands. Under MAS, every spinning sideband is included. A fast MAS rate narrows the central transition but does not remove its second-order lineshape.
  • Natural abundance matters. A coupling to a 1% abundant partner appears as tiny satellites, whereas a coupling to a ~100% abundant partner changes the whole multiplet.
  • Notebook. Panels have Copy notebook code (or Copy as Python) buttons, so a simulation set up here can be reproduced in a notebook.
